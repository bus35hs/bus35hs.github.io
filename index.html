Proyek

Aplikasi mobile

Opang Dunex

Aplikasi untuk pengurus basecamp ojek online. Anggota, kegiatan, iuran, dan pesanan seragam yang dulu tersebar di WhatsApp dan spreadsheet kini tercatat di satu tempat, dengan status pembayaran yang dihitung otomatis.

Sudah dipakai oleh pengurus basecamp.

  • React Native + Expo
  • TypeScript
  • TanStack Query
  • Zod
  • Supabase / PostgreSQL

Keputusan teknis

Riwayat pembayaran yang bisa diaudit

Pembayaran hanya ditambah, tidak diubah atau dihapus. Status lunas dihitung dari total transaksi, dan salah input dikoreksi dengan baris bernominal negatif.

Tidak tercatat dua kali

Setiap pembayaran membawa ID operasi unik, sehingga pengiriman ulang saat sinyal putus tidak menggandakan transaksi.

Edit bersamaan tanpa saling timpa

Data peserta punya nomor versi. Perubahan ditolak kalau pengurus lain sudah mengubah data yang sama lebih dulu.

Aturan akses di database

Hak akses ditegakkan lewat Row Level Security di PostgreSQL, bukan hanya di kode aplikasi.

Aplikasi web, proyek skripsi

Sistem Penawaran Paket Tour

Aplikasi internal untuk menyusun quotation paket wisata dari data vendor, lalu mencetaknya dalam dua versi: untuk klien dan untuk internal perusahaan.

  • PHP + CodeIgniter 3
  • MySQL
  • Bootstrap 5
  • Chart.js

Keputusan teknis

Dokumen lama tetap utuh

Setiap baris quotation disimpan sebagai snapshot, jadi quotation lama tidak ikut berubah saat harga vendor atau konstanta diperbarui.

Harga dihitung sesuai satuannya

Layanan dibedakan per pax dan per unit. Perubahan ini menutup bug yang membuat biaya hotel dan bus membengkak saat peserta lebih dari satu.

Dua versi cetak

Versi klien hanya menampilkan harga jual. Versi internal merinci modal, biaya operasional, dan keuntungan.
